# @jasonscharf/entities

Entity definition primitives for the Tern platform. An entity is an identified graph node — a UUID paired with an IRI — whose properties are triples stored directly against that IRI.

## EntitySchema

Describes a domain entity type: its RDF type IRI and namespace. Register once at startup before using `EntityStore`.

```typescript
import { EntitySchema } from '@jasonscharf/entities';
import { IRI } from '@jasonscharf/core';

const NS = 'http://example.com/ns/';

export const ProductSchema = new EntitySchema({
    typeIri:   new IRI(`${NS}Product`),
    namespace: NS,
});
```

## Defining Properties

Properties are declared in your ontology file (`ontology/product.ttl`) and referenced in code via **generated IRI constants** — never construct property IRI strings by hand.

```typescript
// Generated by `yarn codegen` from ontology/product.ttl
import { nameIRI, priceIRI, descriptionIRI } from './product/types.generated.js';
```

## EntityRecord

The hydrated entity returned by `EntityStore`:

```typescript
interface EntityRecord {
    id:  string;   // UUID
    iri: IRI;      // full entity IRI
    // property values accessible as flat map keyed by predicate IRI value
}
```

## Extension Data

Extensions that need to associate data with an existing entity type write into a **named subgraph** scoped to their namespace and the entity IRI — they do not modify the base entity's data.

```typescript
import { extensionGraph } from '@jasonscharf/entities';

const ANALYTICS_NS = 'http://analytics.example.com/ext/';

// Write extension-owned data for a specific entity
await store.writeExtension(ctx, userIri, ANALYTICS_NS, [
    [lastActiveAtIRI, Literal.dateTime(new Date())],
    [sessionCountIRI, Literal.integer(42)],
]);

// Read it back
const data = await store.readExtension(ctx, userIri, ANALYTICS_NS, [
    lastActiveAtIRI,
    sessionCountIRI,
]);
```

The resulting graph is named `{ANALYTICS_NS}{entityId}` and is owned exclusively by the extension. Extension graphs are soft-deleted when the entity is deleted.

## Utilities

```typescript
import {
    entityIri,   // entityIri(ns, localName, id) → full entity IRI
    newId,       // newId() → UUID string
    idFromIri,   // idFromIri(iri) → local UUID
    localName,   // localName(iri) → local name segment
    toLiteral,   // toLiteral(value) → RDF Literal
    fromLiteral, // fromLiteral(obj) → JS value
} from '@jasonscharf/entities';
```
